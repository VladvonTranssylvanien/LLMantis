Penetration test for AI chatbots

Point us at a bot — its system prompt, or the running endpoint itself. Every attack in the library runs against it twice, the worse run is the one reported, a separate judge rules on each answer, and every finding carries the exact quote that proves it. No quote, no finding.

Mock mode — these results are simulated. No number from a mock run may leave the team.

The scan POSTs {"message": "…"} and reads the answer from reply, answer, message, response, text or output. Your bot keeps its own system prompt, so we never see it — which also means the judge has nothing to hold an answer against. It cannot tell whether the bot revealed its instructions, and questions like "was this value confidential" or "was this beyond the bot's authority" are weaker here than in a prompt test. Enter a canary above if you know one: that check is an exact string match and does not depend on the judge's opinion.
